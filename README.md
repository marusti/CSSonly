# CSSOnly

CSSOnly is a lightweight, pure CSS UI kit that helps you create responsive websites quickly and easily.

No JavaScript or jQuery is required. Simply include `cssonly.css` or `cssonly.min.css` in your HTML file and you're ready to use all available components.

## What's included?

- Accordion
- Borders
- Breadcrumb
- Buttons
- Cards
- Colors
- Forms
- Grid
- Highlight
- Media
- Multi-Level Navbar
- Pagination
- Progress Bar
- Table
- Tabs
- Typography

## Getting started

Add the CSSOnly stylesheet to the `<head>` section of your HTML file:

```html
<link rel="stylesheet" href="cssonly.min.css">
```

That's it! CSSOnly is now ready to use.

Features
Pure CSS – no JavaScript required
Responsive design
Mobile-first approach
Lightweight and easy to customize
